# chat-ai (NVIDIA NIM Chat App)

A modern, high-performance AI Chatbot web application built with **Next.js**, **Tailwind CSS**, and **NVIDIA NIM (Inference Microservices)**.

## Features

- ⚡ **Real-time Streaming Responses**: Fast, smooth streaming responses powered by NVIDIA NIM endpoints.
- 🔑 **Client-Side API Key Configuration**: Enter your free NVIDIA API key directly in the UI (stored securely in browser `localStorage`).
- 🎨 **World-Class Dark UI**: Glassmorphism design, clean typography, responsive layout, and intuitive status indicators.
- 💡 **Quick Prompts & Error Handling**: Helpful starter prompts and inline error banners.

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- An NVIDIA API Key from [build.nvidia.com](https://build.nvidia.com)

### Installation & Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/sarachi6655-spec/chat-ai.git
   cd chat-ai
   ```

2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
5. Enter your NVIDIA API key on the welcome screen to start chatting!
